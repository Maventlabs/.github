## What we build

Mavent is an AI research studio. Instead of one general-purpose AI product, we build a portfolio of AI agents and models — each targeting a specific stage of building a product where generic AI still falls short.

The pattern repeats across every product: AI can draft text, but not write a professional document to a 10/10 standard on its own. AI can generate UI, but not design it well. AI can suggest a model, but not benchmark it against alternatives automatically. Each Mavent product exists to close one of these gaps.

## Products

| Product | What it does | Status |
|---|---|---|
| **[AnyMD](https://github.com/Maventlabs/anymd)** | Generates comprehensive PRDs tailored for AI coding agents (Claude Code, opencode) — including auto-generated `AGENTS.md` with skill/MCP detection instructions | Refinement — usable now, UI tuning and additional features in progress |
| **[Forme](https://github.com/Maventlabs/forme)** | Design intelligence layer for AI coding agents — turns product intent and reference websites into a persistent, machine-readable design system (`DESIGN.md`), enforced by a linter | In development |
| **[Vulpix](https://github.com/vulpixlabs/vulpix)** | AI model/dataset hub with a benchmarking arena and a BYOK (bring-your-own-key) multi-provider playground | Production-ready — minor bug fixes remaining |
| **Ignix** | Fine-tuned AI model line specializing in electronics, launching in three parameter sizes (1B, 4B, 8B) | Fine-tuning phase |
| **Moxa** | AI agent companion focused on healthcare | Research phase |
| **Wireloop** | Fullstack PCB and schematic design application with automatic routing | Documentation finalization |

## Philosophy

Every product here is built with a focus on avoiding generic AI-generated output — curated context, explicit constraints, and technical precision specific to each domain, instead of a thin interface wrapped around a general-purpose model.
